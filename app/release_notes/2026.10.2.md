# 2026.10.2 — 2026-10-10

The container's health status now tells you whether the collector is actually collecting.

Surface labels below are this repo's operator surfaces: Collector is the service itself, Dashboards is what you see in Grafana, and Deployment is the image and the stacks you run to operate it.

## FIXED

- **Health status that looked fine while nothing was collected** `Deployment` — The container could report healthy even when no device's readings were being stored: always with file output off, and on a restart with file output on. It is now healthy only while this run of the collector is storing data, so an unhealthy status means something to look at.

## IMPROVED

- **Smaller published image** `Deployment` — The image no longer carries the project's release documents, only what the collector needs to run.
