# 2026.10.1 — 2026-10-10

Every power strip on newer firmware now reports each outlet, and logs come out in a consistent, machine-readable format.

Surface labels below are this repo's operator surfaces: Collector is the service itself, Dashboards is what you see in Grafana, and Deployment is the image and the stacks you run to operate it.

## FIXED

- **Per-outlet energy for power strips on newer firmware** `Collector` `Dashboards` — HS300 strips on firmware 1.1.2 that were found on the network showed up as a single plug with no outlets, so their per-outlet panels stayed empty; each outlet now reports.
- **Debug files written when turned off** `Collector` — With file output switched off, the collector still wrote a debug file for every device on every poll; it now writes them only when you turn file output on.
- **Security update** `Deployment` — An updated networking library closes a known memory-exhaustion vulnerability.

## IMPROVED

- **Logs** `Collector` — Every log line is now a single JSON record, ready for a log platform, carrying the version and where it came from. Set LOG_FORMAT to text for a readable line when running locally; the old structured-logs switch is no longer needed and is ignored.
- **Device support** `Collector` — The collector runs on the latest release of its device library, which handles newer Kasa firmware natively.
- **Every platform checked before release** `Deployment` — Each published image, on every architecture it ships for, is scanned for known vulnerabilities before anything is uploaded.
- **Bundled database stops leaking disk** `Deployment` — The InfluxDB that ships with the dev and demo stacks keeps its settings on a named volume instead of leaving an orphaned one behind on every restart. Your data is untouched; after upgrading, pass your org and token when running influx commands inside that container.
