# 2026.09.1 — 2026-09-20

Devices that stop answering the network scan no longer disappear from your dashboards.

Surface labels below are this repo's operator surfaces: Collector is the service itself, Dashboards is what you see in Grafana, and Deployment is the image and the stacks you run to operate it.

## FIXED

- **Devices vanished from collection while they were still working** `Collector` — The collector finds your plugs by calling out to the whole network and listening for replies, and it deleted any device that stopped replying. Some devices stop answering that call while working perfectly, so they were removed even though the collector was reading energy data from them seconds earlier.
- **A removed device never came back on its own** `Collector` — Once dropped, the only way back was the same network call it had already stopped answering. Devices now keep their place and are contacted directly, so one that goes quiet returns by itself.
- **Restarting the collector lost devices** `Collector` — Devices not answering the network call at that exact moment were forgotten on restart, and the only fix was typing their addresses into your configuration by hand. The collector now remembers every device it has collected from and re-checks each one when it starts.

## IMPROVED

- **You should never need to know a device's address** `Collector` — That is what discovery is for. Taken together, the three fixes above mean a device found once stays collected for as long as it responds, whatever the network scan does.
- **Reliability** `Collector` — Behind-the-scenes work on the automated tests, including a new one that reproduces the fault above so it cannot come back unnoticed.

## CHANGED

- **One file now describes every way of running the collector** `Deployment` — The separate files for the demo and test setups are gone; each is now an option within the single compose.yml, chosen in your environment file. If you run the collector from this repository, use compose.yml and set COMPOSE_PROFILES — the configuration guide has the values.
