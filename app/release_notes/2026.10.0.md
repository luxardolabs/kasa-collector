# 2026.10.0 — 2026-10-02

A leaner, patched image, with no change to what the collector does.

Surface labels below are this repo's operator surfaces: Collector is the service itself, Dashboards is what you see in Grafana, and Deployment is the image and the stacks you run to operate it.

## FIXED

- **Security updates in the image** `Deployment` — The published image now carries current system security fixes and an updated networking library, and no longer includes packaging tools the collector never uses. The previous image had eleven known high-severity issues that an update can fix; this one has none.

## IMPROVED

- **Smaller, simpler image** `Deployment` — The image contains only the collector and what it needs to run.
- **Every release is checked before it is published** `Deployment` — Each new image is scanned for known vulnerabilities before anything is uploaded, and a release with a fixable one is refused.

## CHANGED

- **Running from the repository** `Deployment` — If you run the collector from a clone of this repository, `make dev-up` and `make up` no longer build the image; they run the version named in your `.env.dev` or `.env.prod`. Set `REGISTRY=ghcr.io` and `TAG` to a released version (this one is `2026.10.0`) — the getting-started guide has the steps. Running the published image directly is unchanged.
