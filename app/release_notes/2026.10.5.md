# 2026.10.5 — 2026-10-25

A small hardening release: the collector can no longer change its own program, and a burst of error messages at startup is gone.

Surface labels below are this repo's operator surfaces: Collector is the service itself, Deployment is the image and the stacks you run, and Docs is the written guides.

## IMPROVED

- **The collector can't change its own program** `Deployment` — The collector runs as a restricted user that can write only to its output folder, so nothing running inside it can alter the program it runs. If you send the exports to a folder other than the default, that folder must be writable by the container's user (uid 1000).
- **Documentation** `Docs` — The configuration guide now says which folders the collector can write to.

## FIXED

- **No more "Unclosed client session" errors at startup** `Collector` — Some newer devices left a connection open the first time the collector reached them, which logged a handful of errors at startup; the connection is now closed and the errors are gone.
