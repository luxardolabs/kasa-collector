## Features

- **`collector_stats` measurement** — each poll cycle writes devices / succeeded / failed / duration_seconds, tagged by cycle, so the collector's own health is visible alongside device data.
- **Hardware-free e2e harness** — `harness/fake_kasa.py` emulates IOT plugs (emeter and non-emeter) and HS300-style strips with per-outlet emeter, so the full collect → store path is testable with no hardware.
- **Four run-stacks** — collector-only, dev, demo and e2e.
- **`utils.sanitize_tag`** — bounds log-forging and InfluxDB series-cardinality blow-up from device-controlled alias strings.

## Refactors

- Repository restructured to the fleet `app/` layout with `app.`-prefixed imports; rebranded to kasa-collector throughout.
- Poetry + multi-stage Docker + Makefile-driven build; nothing requires a host Python.
- `logging.basicConfig` de-duplicated to `app.main`; submodules only `getLogger` + `setLevel`.
- Async InfluxDB client with real batching, replacing the `batch_size=1` write path.

## Schema / Migrations

None. No relational database in this service.

`collector_stats` is a new measurement; existing device measurements and tags are unchanged.

## Infra / Ops

- Multi-arch (amd64/arm64) images published to the private registry, then promoted to `ghcr.io/luxardolabs/kasa-collector` by digest — same artifact, not a rebuild.
- Standard OCI provenance labels added for GHCR repository auto-linking.
- Public GitHub Actions removed; `make check` is the sole gate.
- Committed git hooks wired via `core.hooksPath` for staged and full-history secret scanning.
- Python 3.14 base images.

## Fixes

- **SIGTERM was never handled**, so `docker stop` dropped the container after the grace period (exit 143) instead of shutting down cleanly. Signal handlers now run the full shutdown path; verified exit 0 in 0 seconds.
- **`KEEP_MISSING_DEVICES` was dead config** — `remove_missing_devices()` existed but was never called from `discover_devices()`, so the knob did nothing.
- **`async_retry` retried logic errors**, spending the full retry budget every poll on errors that could never succeed. It now retries only transient network errors.
- **Short InfluxDB tokens leaked in the startup mask** — the first-4/last-4 scheme reproduced any token of 8 characters or fewer verbatim.
- **Tracebacks were discarded everywhere** — no `logger.exception` or `exc_info` in the codebase, so the paths that indicate real bugs logged a single line.
- **Clean shutdown logged at ERROR** — `CancelledError` in `DeviceContext.__aexit__` was reported as an error on every normal stop.
- Device-supplied alias strings reached logs and InfluxDB tags unsanitized.
