## Infra / Ops

**Pre-deploy:** if a host directory is bind-mounted at `/app/output`, it must be writable by uid 1000 (the image's `appuser`). The image no longer owns the whole `/app` by `appuser`, so a root-owned host directory (one Docker created itself) blocks the JSONL exports and `known_devices.json`. The same holds for a custom `KASA_COLLECTOR_OUTPUT_DIR` outside `/app/output`: it must be a mount writable by uid 1000. `KASA_COLLECTOR_HEARTBEAT_FILE` must stay under `/tmp`. **Post-deploy:** none.

- **Production image** (`Dockerfile`): `COPY app /app/app` root-owned, then `chmod -R a+rX,go-w /app/app` so a checkout made under umask 077 still imports; only `/app/output` is chowned to `appuser`. The heartbeat stays in `/tmp`. (KASACOLLEC-110)
- **e2e asserts the running image** (`scripts/e2e-test.sh`): under `/app` and `/opt/venv`, nothing outside `/app/output` may be owned by `appuser` or be group/other-writable, and `/app/output` must be `appuser`'s. (KASACOLLEC-110)
- **Guards:** luxarch 0.322.0 → 0.325.0, luxaudit 0.14.0 → 0.15.0 (luxlint 0.70.0 unchanged). Re-emitted the hook set (30 files, including the new `release-docs-read-guides`; 2 new hooks wired), test-block v8 → v9, release-skill v9 → v10. Adopted the emitted `guard-run` block in place of the hand-written `GUARD_RUN`, so a guard run from a worktree also mounts the main checkout read-only. Measured from a worktree: luxarch 69 pass / 7 inert (was 65 / 11), luxaudit image leg decided instead of inert. (KASACOLLEC-111, KASACOLLEC-89)
- GHCR `:latest` moves to this release (`PUBLIC_LATEST := 1`).

## Fixes

- **`KasaAPI.get_device` leaked an HTTP session on the fallback path.** Strategy 1, `Discover.discover_single`, returns a device; when its `update()` failed after the handshake opened its session, the `Device.connect` fallback overwrote it unclosed. It is now closed (`_close_quietly`) before the fallback replaces it. The strip re-class path was not the cause: `reclass_strip_if_needed` rebuilds on the same protocol object, so nothing is dropped there. (KASACOLLEC-109)
- **The runtime user could rewrite its own code** (`/app/app`), so a compromised collector process could persist across a restart. (KASACOLLEC-110)
