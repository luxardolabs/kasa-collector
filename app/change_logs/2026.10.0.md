The guards move to luxarch 0.249.3 / luxlint 0.60.1 / luxaudit 0.13.0, and with them the image: stacks pin immutable tags, the runtime ships only the app, and a release scans its own candidate before it pushes.

## Features

- **`make dev-deploy` / `make dev-pin`.** `dev-deploy` builds the runtime stage, scans it, pushes `:sha-<commit>`, moves the `:dev` alias onto it, writes `TAG=sha-<commit>` into `.env.dev` (one line rewritten, nothing else read or printed) and restarts the dev stack. `dev-pin TAG=…` is the rollback path: it checks the registry holds the tag before pinning a stack to it.
- **`make release-scan`.** Builds the release candidate locally under the bare `kasa-collector:test`, `docker save`s it and runs `luxaudit --image-archive`; any fixable HIGH/CRITICAL refuses the release before the multi-arch push. Same shape as the guards' own releases.
- `release` and `dev-deploy` refuse a dirty working tree (`guard-clean-tree`): a `sha-` or version tag built from uncommitted changes would name a commit that does not contain its bits.

## Infra / Ops

**Pre-deploy: none. Post-deploy: on the dev host, deploy with `make dev-deploy` from now on.** A `.env.dev` still holding `TAG=dev` keeps working but is the moving tag the guards now red.

- Guard pins: luxarch 0.193.0 → 0.249.3, luxlint 0.55.0 → 0.60.1, luxaudit 0.9.0 → 0.13.0.
- **Runtime image.** Deps install into `/opt/venv` in the builder and only the venv is copied; the runtime previously copied the builder's whole system site-packages, Poetry's dependency tree included. pip is removed from the runtime (it vendors urllib3/msgpack/setuptools that no upgrade reaches) and the runtime layer runs `apt-get upgrade`. Result: 2026.09.1 shipped 11 fixable HIGH (7 OS: openssl, libssl3t64, libpcre2; 4 Python: urllib3, msgpack, setuptools); this candidate scans **0**.
- urllib3 2.7.0 → 2.8.0 (CVE-2026-97687 / 97688 / 97689). The only lockfile change.
- `.env.example` documents `TAG=sha-<commit>` (dev) / the released version (prod); `.env.demo` drops the unused `FAKE_TAG`.
