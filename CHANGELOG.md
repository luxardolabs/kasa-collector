# Change Log

Per-version **internal/technical** change logs live in [`app/change_logs/`](app/change_logs/) — one file per released version, named `{VERSION}.md`. They record what actually changed in the code: issues closed, features, refactors, infra/ops, and fixes, written for the dev and ops team.

For the user-facing view of the same releases, see [`RELEASE_NOTES.md`](RELEASE_NOTES.md).

- Format: [`app/change_logs/writing-guide.md`](app/change_logs/writing-guide.md)
- Process: `luxarch --doc FLEET-RELEASE-PROCESS`

The current version is in [`VERSION`](VERSION); every release ships both documents.
